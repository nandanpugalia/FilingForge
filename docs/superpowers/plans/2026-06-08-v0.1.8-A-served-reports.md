# v0.1.8 — A: Served Reports + Report-v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Make generated reports open over http (so citations work in Safari), securely; and upgrade the report helper to the dynamic "Direction-C v2" look.

**Architecture:** The Rust shell generates a random **port** (8765→8766-8775 fallback) + a per-session **auth token** at startup, passes both to the Python sidecar via env, and exposes them to the UI via a Tauri command. The FastAPI sidecar adds a **path-restricted, token-gated** static route serving the library root. The app detects reports in `research_report/` folders and opens them at `http://127.0.0.1:<port>/…?token=…` in the default browser. The engine's `_filingforge-report.md` helper becomes the v2 template (chart degrades gracefully).

**Tech Stack:** Tauri v2 (Rust + React/TS), Python FastAPI sidecar (pytest), vitest.

- [ ] **Step 3: Implement `api/serve.py`:**

```python
import os
from pathlib import Path
from fastapi import APIRouter, Request, HTTPException
from fastapi.responses import FileResponse

router = APIRouter()

def _root() -> Path:
    return Path(os.environ.get("FF_LIBRARY_ROOT", "")).expanduser().resolve()

@router.get("/lib/{rel:path}")
def serve(rel: str, request: Request):
    if request.query_params.get("token") != os.environ.get("FF_TOKEN"):
        raise HTTPException(403, "forbidden")
    if rel.endswith("/") or rel == "":
        raise HTTPException(404, "no listing")
    root = _root()
    target = (root / rel).resolve()
    if not target.is_relative_to(root) or target.is_symlink() or not target.is_file():
        raise HTTPException(404, "not found")
    resp = FileResponse(target)
    resp.headers["Access-Control-Allow-Origin"] = "null"   # deny cross-origin
    return resp
```

### Task A3: App detects reports + "Open report" over http

**Files:** Modify `ui/src/api.ts`, `ui/src/components/LibraryOverlay.tsx`, `ui/src/App.tsx`.

- [ ] **Step 1: Runtime base URL + token.** In `api.ts`, on first use fetch `engine_info` (Tauri)
  and cache `{port, token}`; export `reportUrl(relPath)` → `http://127.0.0.1:<port>/lib/<relPath>?token=<token>`.
  Non-Tauri (tests/dev): fall back to `API_BASE` + no token.

```ts
let _engine: { port: number; token: string } | null = null;
export async function engineInfo() {
  if (_engine) return _engine;
  if (!isTauri()) return (_engine = { port: 8765, token: "" });
  const { invoke } = await import("@tauri-apps/api/core");
  return (_engine = await invoke("engine_info"));
}
export async function reportUrl(relPath: string): Promise<string> {
  const e = await engineInfo();
  const q = e.token ? `?token=${encodeURIComponent(e.token)}` : "";
  return `http://127.0.0.1:${e.port}/lib/${relPath}${q}`;
}
```
