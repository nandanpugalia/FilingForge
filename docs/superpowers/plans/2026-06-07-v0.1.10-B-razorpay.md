# v0.1.10 — B: Monetization (Razorpay + Worker, poll-based) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`).
> Supersedes the Instamojo plan. Council-audited 2026-06-07 (Gemini 3 Pro + GPT-5.5/kimi + GLM-5.1) — all fixes baked in below. **Deep-link CUT for v1** (poll is primary; add `filingforge://` in v1.1).

**Goal:** Sell the first paid skill (**Concall Decoder, ₹3,000**) seamlessly: Get → pay in the system browser (Razorpay) → switch back to the app → it has already auto-unlocked (poll). Paste-code is the co-equal fallback. No payment ever strands a buyer.

**Architecture:** A **Cloudflare Worker + KV** is the source of truth and the only holder of the Razorpay secret. App generates a `session_id` (UUID) → asks the Worker `POST /checkout` → Worker creates a Razorpay **Payment Link** via API (**amount hardcoded ₹3,000 server-side**, `notes.session`, `callback_url=…/thanks?session=`) → app opens the `short_url` in the system browser → user pays → Razorpay **`payment_link.paid` webhook** → Worker verifies `X-Razorpay-Signature` (HMAC-SHA256 over raw body) **and amount/currency/status**, writes `sess:<id>` + `pay:<payment_id>→<id>` → app **polls** `GET /redeem?session=<id>` → gets the **watermarked .md** → installs. The thanks page shows the session (paste-code) + captures `razorpay_payment_id` for the **`/redeem-fallback`** (webhook-loss insurance).

**Tech Stack:** Cloudflare Worker (TS) + KV, Razorpay (Payment Links API + webhook), React/TS. (No Tauri deep-link in v1.)

```ts
export interface Env { KV: KVNamespace; SKILLS: KVNamespace;
  RAZORPAY_KEY_ID: string; RAZORPAY_KEY_SECRET: string; RAZORPAY_WEBHOOK_SECRET: string }
const CAP = 10;                        // generous device limit; KV race acceptable at this cap
const PRICE = 300000;                  // ₹3,000 in paise — server-side truth
const SKILL = "concall-decoder";
const UUID = /^[0-9a-f]{8}-[0-9a-f]{4}-4[0-9a-f]{3}-[89ab][0-9a-f]{3}-[0-9a-f]{12}$/i;
const j = (o: unknown, s = 200) => Response.json(o, { status: s });

// Verify Razorpay webhook: HMAC-SHA256 over the RAW body, hex, vs X-Razorpay-Signature.
async function sigOk(raw: string, header: string | null, secret: string): Promise<boolean> {
  if (!secret || !header) return false;
  const key = await crypto.subtle.importKey("raw", new TextEncoder().encode(secret),
    { name: "HMAC", hash: "SHA-256" }, false, ["verify"]);
  const bytes = header.length % 2 ? null : Uint8Array.from(header.match(/.{2}/g)!.map(h => parseInt(h, 16)));
  if (!bytes) return false;
  return crypto.subtle.verify("HMAC", key, bytes, new TextEncoder().encode(raw));
}
// Un-watermarked-proof: prepend unconditionally (the skill .md has NO frontmatter). BOM-safe.
const watermark = (md: string, email: string) =>
  md.replace(/^﻿?/, m => `${m}<!-- FilingForge · Licensed to ${email} · do not redistribute -->\n\n`);

const log = (o: object) => console.log(JSON.stringify(o));   // no secrets / full emails

export default {
  async fetch(req: Request, env: Env): Promise<Response> {
    const url = new URL(req.url);

    // --- create a per-session ₹3,000 payment link (amount is server-side; client can't tamper) ---
    if (req.method === "POST" && url.pathname === "/checkout") {
      const { session } = await req.json().catch(() => ({})) as { session?: string };
      if (!session || !UUID.test(session)) return new Response("bad session", { status: 400 });
      const rz = await fetch("https://api.razorpay.com/v1/payment_links", {
        method: "POST",
        headers: { "content-type": "application/json",
          authorization: "Basic " + btoa(`${env.RAZORPAY_KEY_ID}:${env.RAZORPAY_KEY_SECRET}`) },
        body: JSON.stringify({ amount: PRICE, currency: "INR", accept_partial: false,
          description: "FilingForge — Concall Decoder",
          notes: { session, skill: SKILL },
          callback_url: `https://filingforge.pages.dev/thanks?session=${session}`, callback_method: "get" }),
      });
      const d = await rz.json() as any;
      if (!d?.short_url) { log({ e: "checkout_fail", session, status: rz.status }); return new Response("gateway error", { status: 502 }); }
      return j({ url: d.short_url });
    }

    // --- Razorpay webhook (subscribe ONLY payment_link.paid + refund.processed) ---
    if (req.method === "POST" && url.pathname === "/webhook/razorpay") {
      const raw = await req.text();
      if (!(await sigOk(raw, req.headers.get("X-Razorpay-Signature"), env.RAZORPAY_WEBHOOK_SECRET)))
        return new Response("bad signature", { status: 401 });
      const evt = JSON.parse(raw);
      if (evt.event === "payment_link.paid") {
        const plink = evt?.payload?.payment_link?.entity;
        const pay = evt?.payload?.payment?.entity;
        const sid = plink?.notes?.session;                       // notes live on the LINK entity
        if (!sid || !UUID.test(sid)) return new Response("ok");
        if (pay?.amount !== PRICE || pay?.currency !== "INR" || pay?.status !== "captured") {
          log({ e: "amount_mismatch", sid, amount: pay?.amount }); return new Response("ok"); // ack, don't fulfil
        }
        if (await env.KV.get(`sess:${sid}`)) return new Response("ok"); // idempotent
        await env.KV.put(`sess:${sid}`, JSON.stringify({ skill_id: SKILL, email: pay?.email || "", payment_id: pay?.id, status: "paid" }));
        await env.KV.put(`act:${sid}`, "0");
        if (pay?.id) await env.KV.put(`pay:${pay.id}`, sid);     // reverse index for refunds
        log({ e: "paid", sid }); return new Response("ok");
      }
      if (evt.event === "refund.processed") {
        const payId = evt?.payload?.refund?.entity?.payment_id;
        const sid = payId && await env.KV.get(`pay:${payId}`);
        if (sid) { const e = await env.KV.get(`sess:${sid}`);
          if (e) await env.KV.put(`sess:${sid}`, JSON.stringify({ ...JSON.parse(e), status: "refunded" })); }
        return new Response("ok");
      }
      return new Response("ok");                                  // ack everything else
    }

    // --- redeem by session (the session UUID IS the code) ---
    if (req.method === "GET" && url.pathname === "/redeem") {
      const sid = url.searchParams.get("session") || "";
      const e = await env.KV.get(`sess:${sid}`);
      if (!e) return j({ status: "pending", retry_in: 3 }, 202);
      const rec = JSON.parse(e);
      if (rec.status === "refunded") return new Response("not found", { status: 403 });
      const acts = parseInt(await env.KV.get(`act:${sid}`) || "0", 10);
      if (acts >= CAP) return new Response("not found", { status: 403 });
      const md = await env.SKILLS.get(rec.skill_id);
      if (!md) return new Response("not found", { status: 404 });
      await env.KV.put(`act:${sid}`, String(acts + 1));          // KV race acceptable at cap 10
      log({ e: "redeem", sid, n: acts + 1 });
      return new Response(watermark(md, rec.email), { headers: {
        "content-type": "text/markdown", "content-disposition": 'attachment; filename="concall-decoder.md"',
        "access-control-allow-origin": "*" } });
    }

    // --- webhook-loss insurance: reconcile straight from Razorpay using the payment id ---
    if (req.method === "POST" && url.pathname === "/redeem-fallback") {
      const { session, payment_id } = await req.json().catch(() => ({})) as { session?: string; payment_id?: string };
      if (!session || !UUID.test(session) || !payment_id) return new Response("bad request", { status: 400 });
      if (!(await env.KV.get(`sess:${session}`))) {
        const rz = await fetch(`https://api.razorpay.com/v1/payments/${payment_id}`, {
          headers: { authorization: "Basic " + btoa(`${env.RAZORPAY_KEY_ID}:${env.RAZORPAY_KEY_SECRET}`) } });
        const p = await rz.json() as any;
        if (p?.status !== "captured" || p?.amount !== PRICE || p?.currency !== "INR" || p?.notes?.session !== session)
          return new Response("not found", { status: 403 });
        await env.KV.put(`sess:${session}`, JSON.stringify({ skill_id: SKILL, email: p.email || "", payment_id, status: "paid" }));
        await env.KV.put(`act:${session}`, "0");
        await env.KV.put(`pay:${payment_id}`, session);
      }
      // fall through to the same redeem path
      const acts = parseInt(await env.KV.get(`act:${session}`) || "0", 10);
      if (acts >= CAP) return new Response("not found", { status: 403 });
      const md = await env.SKILLS.get(SKILL);
      const rec = JSON.parse((await env.KV.get(`sess:${session}`))!);
      await env.KV.put(`act:${session}`, String(acts + 1));
      return new Response(watermark(md!, rec.email), { headers: {
        "content-type": "text/markdown", "content-disposition": 'attachment; filename="concall-decoder.md"' } });
    }
    return new Response("not found", { status: 404 });
  },
};
```
Notes: no `/admin` endpoint (reset via `wrangler kv key put act:<sid> 0`). No `ADMIN_SECRET`/`APP_SECRET` (an OSS app can't hold a secret; `/checkout` is safe because the **amount is server-side** and creating a link gives an attacker nothing without paying ₹3,000 — add a Cloudflare **rate-limit rule** on `/checkout` to prevent link-spam). KV cap-race accepted at cap 10.
