# v0.1.8 — B: Monetization (System-Browser + Deep-Link Paywall) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Sell the first paid skill (Concall Decoder, ₹3,000) through a seamless flow: Get → pay in the system browser → return to the app via a deep link → skill auto-installs. With three-layer fallback so a payment never strands a buyer.

**Architecture:** Instamojo is the payment + email gate. A **Cloudflare Worker + KV** is the source of truth: an Instamojo **webhook** records each purchase (UUID redeem code, watermark email, activation count); `/redeem` returns the watermarked `.md` (202-pending during the webhook race; activation cap 5; rate-limited). The app opens checkout in the **system browser**; Instamojo's success redirect is a custom **deep link** `filingforge://redeem?code=…` that re-focuses the app and installs. Fallbacks: paste-the-code, and the existing Import.

**Tech Stack:** Cloudflare Worker (TS) + KV, Tauri v2 deep-link + single-instance, React/TS, Instamojo.

```ts
export interface Env { KV: KVNamespace; INSTAMOJO_SALT: string; ADMIN_SECRET: string; SKILLS: KVNamespace }
const CAP = 5;

async function hmacOk(params: URLSearchParams, salt: string): Promise<boolean> {
  // Instamojo MAC: sha1(HMAC) over fields sorted by key, '|'-joined, key=salt.
  const fields = [...params.entries()].filter(([k]) => k !== "mac").sort(([a],[b]) => a < b ? -1 : 1);
  const msg = fields.map(([,v]) => v).join("|");
  const key = await crypto.subtle.importKey("raw", new TextEncoder().encode(salt),
    { name: "HMAC", hash: "SHA-1" }, false, ["sign"]);
  const sig = await crypto.subtle.sign("HMAC", key, new TextEncoder().encode(msg));
  const hex = [...new Uint8Array(sig)].map(b => b.toString(16).padStart(2, "0")).join("");
  return hex === (params.get("mac") || "").toLowerCase();
}

const watermark = (md: string, email: string) =>
  md.replace(/^---\n/, `---\nlicensed_to: ${email}\n`);   // stamp frontmatter

export default {
  async fetch(req: Request, env: Env): Promise<Response> {
    const url = new URL(req.url);
    if (req.method === "POST" && url.pathname === "/webhook/instamojo") {
      const body = new URLSearchParams(await req.text());
      if (!(await hmacOk(body, env.INSTAMOJO_SALT))) return new Response("bad mac", { status: 401 });
      const status = body.get("status") || body.get("payment_status");
      const purchaseId = body.get("payment_id")!;
      const existing = await env.KV.get(`pay:${purchaseId}`);
      if (status === "Refunded" && existing) {
        await env.KV.put(`pay:${purchaseId}`, JSON.stringify({ ...JSON.parse(existing), status: "refunded" }));
        return new Response("ok");
      }
      if (existing) return new Response("ok"); // idempotent / replay-safe
      const code = crypto.randomUUID();
      const rec = { code, skill_id: "concall-decoder", email: body.get("buyer")||body.get("buyer_email"),
        name: body.get("buyer_name"), purchase_id: purchaseId, status: "paid" };
      await env.KV.put(`pay:${purchaseId}`, JSON.stringify(rec));
      await env.KV.put(`code:${code}`, purchaseId);
      await env.KV.put(`act:${code}`, "0");   // activations counter, separate key (replay-safe)
      return new Response("ok");
    }
    if (req.method === "POST" && url.pathname === "/redeem") {
      const { code } = await req.json() as { code: string };
      const purchaseId = await env.KV.get(`code:${code}`);
      if (!purchaseId) return new Response(JSON.stringify({ status: "pending", retry_in: 3 }), { status: 202 });
      const rec = JSON.parse((await env.KV.get(`pay:${purchaseId}`))!);
      if (rec.status === "refunded") return new Response("not found", { status: 403 }); // identical msg
      const acts = parseInt(await env.KV.get(`act:${code}`) || "0", 10);
      if (acts >= CAP) return new Response("not found", { status: 403 });               // identical msg
      const md = await env.SKILLS.get(rec.skill_id);
      if (!md) return new Response("not found", { status: 404 });
      await env.KV.put(`act:${code}`, String(acts + 1));
      return new Response(watermark(md, rec.email || ""), { headers: { "content-type": "text/markdown" } });
    }
    if (req.method === "GET" && url.pathname === "/skills-manifest") {
      const v = await env.SKILLS.get("concall-decoder:version") || "1";
      return Response.json({ "concall-decoder": v });
    }
    if (req.method === "POST" && url.pathname === "/admin/reset-activations") {
      if (req.headers.get("x-admin") !== env.ADMIN_SECRET) return new Response("no", { status: 403 });
      const { code } = await req.json() as { code: string };
      await env.KV.put(`act:${code}`, "0");
      return new Response("ok");
    }
    return new Response("not found", { status: 404 });
  },
};
```
