# v0.1.7.1 — Beta-Feed Release Gate (C) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in pre-release update channel so future releases can be QA'd on a beta feed before promoting to all users — and ship it *alone* as v0.1.7.1 so it exists before it's needed to gate v0.1.8.

**Architecture:** A Settings toggle ("Get pre-release updates", default OFF) persists a `beta` preference. The Tauri updater is driven from **Rust commands** that build the updater with a **runtime-chosen endpoint** (stable = GitHub `releases/latest` which ignores prereleases; beta = `latest-beta.json` on GitHub Pages). CI publishes the beta feed to `gh-pages` on every tag; "promote" = un-marking the GitHub release as prerelease. The JS `useUpdate` hook calls the Rust commands with the toggle value instead of the JS plugin's `check()`.

**Tech Stack:** Tauri v2 (Rust `tauri-plugin-updater` v2 + React/TS), GitHub Actions, GitHub Pages.

---

## Why a Rust command (read first)

Tauri v2 reads `plugins.updater.endpoints` from `tauri.conf.json` at **build time**; the JS `check()` API has **no endpoint override**. Runtime channel switching therefore requires the Rust `UpdaterExt::updater_builder().endpoints(...)` API. Task 1 is a spike that *confirms this exact API* before the dependent tasks rely on it. If the spike reveals a different shape, update Tasks 3-5 to match before proceeding.

```rust
// API confirmed in the Task 1 spike: tauri_plugin_updater::UpdaterExt::updater_builder()
//   .endpoints(Vec<Url>)?.build()?.check().await -> Option<Update>; Update has .version/.body
//   and .download_and_install(on_chunk, on_done).
use serde::Serialize;
use tauri_plugin_updater::UpdaterExt;

const STABLE: &str = "https://github.com/nandanpugalia/FilingForge/releases/latest/download/latest.json";
const BETA: &str = "https://nandanpugalia.github.io/FilingForge/latest-beta.json";

fn feed(beta: bool) -> &'static str { if beta { BETA } else { STABLE } }

#[derive(Serialize)]
pub struct UpdateInfo { pub version: String, pub notes: Option<String> }

#[tauri::command]
pub async fn check_for_update(app: tauri::AppHandle, beta: bool) -> Result<Option<UpdateInfo>, String> {
    let updater = app.updater_builder()
        .endpoints(vec![feed(beta).parse().map_err(|e| format!("bad feed url: {e}"))?])
        .map_err(|e| format!("endpoints: {e}"))?
        .build().map_err(|e| format!("build: {e}"))?;
    match updater.check().await {
        Ok(Some(u)) => Ok(Some(UpdateInfo { version: u.version.clone(), notes: u.body.clone() })),
        Ok(None) => Ok(None),
        Err(e) => Err(format!("{e}")),
    }
}
```

### Task 4: Rust — `install_update` command (download + install, runtime endpoint)

**Files:** Modify `ui/src-tauri/src/updater_cmd.rs`, `ui/src-tauri/src/lib.rs`

- [ ] **Step 1: Add the install command** to `updater_cmd.rs` (emits progress events the UI listens for):

```rust
#[tauri::command]
pub async fn install_update(app: tauri::AppHandle, beta: bool) -> Result<(), String> {
    use tauri::Emitter;
    let updater = app.updater_builder()
        .endpoints(vec![feed(beta).parse().map_err(|e| format!("bad feed url: {e}"))?])
        .map_err(|e| format!("endpoints: {e}"))?
        .build().map_err(|e| format!("build: {e}"))?;
    let update = updater.check().await.map_err(|e| format!("check: {e}"))?
        .ok_or_else(|| "no update available".to_string())?;
    let mut downloaded: usize = 0;
    update.download_and_install(
        |chunk, total| {
            downloaded += chunk;
            let pct = total.map(|t| (downloaded as f64 / t as f64 * 100.0) as u32).unwrap_or(0);
            let _ = app.emit("update://progress", pct);
        },
        || { let _ = app.emit("update://done", ()); },
    ).await.map_err(|e| format!("install: {e}"))?;
    Ok(())
}
```

    needs: [build]
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with: { ref: gh-pages, fetch-depth: 0 }
        continue-on-error: true   # first run: branch may not exist yet
      - name: Download latest.json from the release
        run: |
          TAG="${GITHUB_REF_NAME}"
          curl -sL "https://github.com/nandanpugalia/FilingForge/releases/download/${TAG}/latest.json" -o latest-beta.json
          test -s latest-beta.json
      - name: Commit to gh-pages
        run: |
          git config user.name "github-actions"; git config user.email "actions@github.com"
          git add latest-beta.json
          git commit -m "beta feed: ${GITHUB_REF_NAME}" || echo "no change"
          git push origin HEAD:gh-pages
